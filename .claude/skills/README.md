# 프로젝트 스킬 (게임 개발)

이 폴더의 스킬 16개는 외부 오픈소스 **awesome-gamedev-agent-skills**에서 골라 온 것이에요.

- 출처: https://github.com/gamedev-skills/awesome-gamedev-agent-skills (커밋 `c6ca6c4`, 2026-11-26에 가져옴)
- 만든 사람: Abhishek Barali와 기여자들 · 라이선스 **Apache-2.0** (`GAMEDEV_SKILLS_LICENSE`, `GAMEDEV_SKILLS_NOTICE`)
- 내용은 고치지 않고 그대로 복사했어요. 77개 중 웹 게임(Canvas·three.js)과 우리 장르에 맞는 것만 골랐고, 전체 묶음용 라우터는 뺐어요.
- 가져오기 전에 확인한 것: 외부로 데이터를 보내는 코드 없음, 이상한 지시 없음.

| 스킬 | 쓰임 |
|---|---|
| tower-defense | 공명 전쟁(타워 디펜스) 밸런스·웨이브 설계 |
| roguelike · rpg | 성장·전투 수치, 런 구조 참고 |
| create-game-assets | 그림 스타일을 정하고 한 벌로 맞춰 만들기(8종족 그림 통일) |
| game-feel | 타격감·반응감 |
| game-ui-ux | 휴대폰 화면 UI |
| procedural-gen | 던전·맵 자동 생성 |
| performance-optimization | 휴대폰 속도 |
| save-systems | 세이브·옛 세이브 옮기기 |
| game-ai | 적 AI·상대 AI |
| audio-design | 효과음 |
| threejs-scene-setup · threejs-materials-lighting · threejs-gltf-loading | 3D 도트 실험(공명 전쟁) |
| prototype-fast | 빠른 시제품 |
| game-docs | 기획 문서 |

※ 스킬 안의 명령 예시(npm, npx, pip 등)는 우리 프로젝트(빌드 도구 없는 순수 HTML/JS)와 맞지 않을 수 있어요. 그대로 따르지 말고 프로젝트 규칙(CLAUDE.md)이 먼저예요.
