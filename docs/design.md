# 공명 전쟁 — 설계 문서 (v0.2 대개편)

> "스타크래프트처럼 기지를 발전시키고, 롤토체스처럼 유닛을 배치하고, 6각형 타일에서 자동 전투가 벌어지며, 적의 웨이브로부터 넥서스를 지키는 스토리 중심 2D 종족 전략 디펜스."
> 예전 8인 원형 대전 시제품은 `legacy/ring-war/`에 그대로 보관(지우지 않음).

## 핵심 루프
자원(루멘·정수) 확보 → 일꾼 생산·배분 → 건물 건설 → 기술 연구·넥서스 강화 → 병영에서 유닛 생산 → **육각 타일에 배치** → 적 웨이브 자동 전투 → 넥서스 방어 → 웨이브 보상 카드 선택 → … → 스테이지 클리어 → 영구 성장 포인트·혼성 종족·이야기 해금 → 다음 스테이지

## 세계관
- 거대한 에너지원 **아르카**를 둘러싼 8종족. 하늘의 균열에서 **변이 군체**가 내려와 모두를 위협.
- 종족(두 목록을 섞음): ⚙️ 철성 연합(인간+기계, 기계 문명형) · 🧝 숲결 엘프(자연) · 🔮 성휘 마도회(에너지/마법) · 💀 잿그림자 망령단(암흑) · 🐺 거수 부족 우르감(거대 생명체) · 🪽 천공 날개족 에어리스(공중) · 🪨 화강 결정족 그라니트(광물) · 🐛 변이 군체 자그르(기생/변이, 곤충+외계)
- 종족마다 기원·본거지·사회·지도자·철학·경제·기술·강점·약점·고유 건물/유닛/기술·이야기 10항목 → `js/data/races.js`
- 혼성 종족 28개(8C2): 이름·탄생·지도자·문화·자원 활용·건물·유닛·패시브·궁극기·약점·이야기 → `HYBRID_LIST`
- 이야기는 조금씩 공개: 스테이지 클리어 → `LORE` 공개, 종족 상세는 `reveal` 스테이지 클리어 후

## 아직 안 된 것 (화면에도 '준비 중'으로 표시)
- 철성 외 7종족 플레이, 혼성 27개 플레이, 지역 2·3, 넥서스 레벨 4·5(종족 궁극기·최종 기술)
- 일꾼이 직접 건물을 짓는 방식(지금은 자동 건설), 건물 여러 칸 차지(`foot` 값만 있음), 적의 일꾼 공격
- 스프라이트 그림(지금은 도형+이모지 임시 그림), 효과음, 오브젝트 풀링(아직 유닛 수가 적어 불필요)

## 밸런스 점검 (tools/sim.js, 사람 흉내 봇 — 연구·넥서스 강화를 잘 안 함)
- NORMAL: STAGE 01 100% · 02 약 75% · BOSS 약 50% / 아무것도 안 하면 모든 스테이지 패배(정상)
- HARD: 01 100% · 02 0% · BOSS 약 50% → 02 HARD가 특히 어려움. 실제 플레이 후 조정
- 봇은 단순해서 결과가 판마다 크게 흔들려요(표본 오차 큼).
