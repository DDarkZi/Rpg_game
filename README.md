# 공명 전쟁

대균열로 부서진 일곱 세계가 하나의 고리로 이어졌다 — 8종족 2D 도트 타워 디펜스 대전.

- 8명이 원형으로 연결: 유닛을 사서 **다음 사람** 판으로 보내고, 내 판은 타워로 막아요.
- 종족 8개(인간·마법·기계·곤충·외계·동물·엘프·언데드), 두 종족을 합치는 **공명**으로 조합 타워·유닛.
- 지금은 시제품: 인간·기계·곤충 + 조합 3개 플레이 가능.

플레이: https://ddarkzi.github.io/Rpg_game/ · 기획: `docs/design.md` · 시뮬: `node tools/sim.js 30`
