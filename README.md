# 공명 전쟁

거대한 에너지원 「아르카」를 둘러싼 여덟 종족 — **기지 운영 + 육각 타일 배치 + 자동 전투 디펜스**.

- 일꾼으로 🔷루멘·🟣정수를 캐고, 병영·추출기·수호탑을 짓고, 유닛을 뽑아 육각 칸에 배치해 넥서스를 지켜요.
- 지금(v0.2 MVP): 철성 연합 + 혼성 「반석 기사단」, 스테이지 3개(웨이브 10, 보스 1), 기술 8, 난이도 3, 영구 성장, 저장.
- 8종족·혼성 28 설정은 데이터로 준비돼 있고, 나머지는 '준비 중'.
